# ASU Capstone x KARA x Seeds of Success: Responsible AI Toolkit

This repo contains the deliverables of the Responsible AI Toolkit developed for Seeds of Success and KARA from Fall '26 to Spring '27, including:
- Source code of the website to be integrated into the SoS website
- The white paper detailing SoS's philosophy on what responsible AI usage means
- The public surfaces audit, including details on AI transparency

# Source Code
The website was developed using the React framework, built with Node.js, and bootstrapped by Vite. To install Node.js in your editor/environment, please visit https://nodejs.org/en/download.

All source code is available here. Once downloaded, traverse to the parent folder and use `npm run dev` in your terminal to see the current build.
